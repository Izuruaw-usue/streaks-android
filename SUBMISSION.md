## Идея приложения
Streaks — мобильный трекер привычек. Пользователь регистрируется, создаёт ежедневные или еженедельные
привычки с напоминанием, отмечает их выполнение каждый день и следит за прогрессом с помощью счётчика
серии дней подряд (streak), календаря на месяц и статистики. Цель приложения — сделать формирование
полезных привычек простым и мотивирующим.

## Figma: как выполнены требования
- 14 экранов (минимум 10): Splash, Onboarding, Sign up (error), Sign up, Log in, Home (empty), Add habit,
  Home, Habit details, Edit habit, Calendar, Statistics, Profile, Settings.
- Интерактивный прототип: 42 перехода; основной сценарий — Splash → Onboarding → Sign up → Home (empty) →
  Add habit → Home → Habit details.
- Единый стиль: переменные цветов, текстовые стили, один набор иконок (контурные иконки в стиле Lucide),
  шрифт Inter.
- Состояния: кнопка default / pressed / disabled, поле ввода default / focused / filled / error,
  пустой список, выполненная и невыполненная привычка, выбранная иконка и сегментированный переключатель,
  переключатели on / off.
- Компоненты: Button (6 вариантов), Input (4 варианта), NavBar (4 варианта).

## Android: как выполнены требования
- Соответствие дизайну: те же палитра, скругления, отступы и иконки (vector drawables);
  11 фрагментов на 14 экранов дизайна.
- Навигация: Navigation Component + BottomNavigationView.
- Формы с валидацией: sign up, log in, форма привычки.
- Списки: список привычек (RecyclerView + ListAdapter), сетка календаря, строки статистики.
- Сохранение данных: Room + SharedPreferences.
- Архитектура: MVVM, ViewModel + StateFlow, доступ к данным через DAO.
